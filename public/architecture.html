Enter a prompt; click Run query()

The student writes a small question. No model request happens until Run query() is pressed.

$("form").addEventListener("submit", async (event) => {
  event.preventDefault(); if (running) return;
  running = true; finalResult = false; ($("run") as HTMLButtonElement).disabled = true;
  $("answer").textContent = ""; $("events").replaceChildren(); $("status").textContent = "Running";

04

query({ prompt, options })

The agent function calls query exactly once. The SDK launches its local runtime; it does not create a Managed Agents resource.

const conversation = query({
  prompt,
  options: {
    model: MODEL,
    tools: [],
    settingSources: [],
    mcpServers: {},
    plugins: [],
    persistSession: false,
    maxTurns: 1,
    maxBudgetUsd: 0.10,
    cwd,
    abortController,
  },

How this code explains step 4

The agent function calls query once. These options belong to that single SDK invocation; the complete function closes the conversation in finally.

06

Claude response and usage

Claude returns model output and usage. This cloud boundary is separate from the browser-to-host connection.

Source: src/agent.ts · lines 30–35

Selected source excerpt; surrounding context may be omitted.

if (message.type === "result") {
  const success = message.subtype === "success" && !message.is_error;
  return [{ type: "result", status: success ? "success" : message.subtype === "success" ? "error" : message.subtype,
    text: message.subtype === "success" ? message.result : message.errors.join("\n"),
    sessionId: message.session_id, costUsd: message.total_cost_usd, turns: message.num_turns }];
}

How this code explains step 6

This result projection reads the real model outcome and usage-related fields returned through the SDK. It is the application observation boundary, not a custom Claude API implementation.

07

Async SDK messages: assistant and result

for await...of consumes SDK messages. Assistant text and the final result are different message types.

Source: src/agent.ts · lines 62–67

Selected source excerpt; surrounding context may be omitted.

for await (const message of conversation) {
  for (const event of projectMessage(message)) {
    if (event.type === "result") gotResult = true;
    emit(event);
  }
}

How this code explains step 7

The for-await loop consumes SDK messages and emits their explicit student-facing projection. It does not invoke a new agent for each message.

08

Stream selected JSON events

The server forwards a small, explicit event projection as newline-delimited JSON. It does not stream raw runtime configuration.

Source: src/server.ts · lines 52–52

Selected source excerpt; surrounding context may be omitted.

const emit = (event: unknown) => { if (!res.destroyed) res.write(JSON.stringify(event) + "\n"); };

How this code explains step 8

The server writes each selected event as one JSON line. Private runtime configuration and credentials are not included in this projection.
