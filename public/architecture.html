01

Enter a prompt; click Run query()

The student writes a small question. No model request happens until Run query() is pressed.

02

POST /api/query with JSON input

The browser sends only the prompt to its own local server. It never receives the API key.

03

Validate prompt and configuration

The server validates the input and allows only one active query.

04

query({ prompt, options })

The agent function calls query exactly once. The SDK launches its local runtime; it does not create a Managed Agents resource.

05

Send model request with tools disabled

The local runtime makes the model request. tools: [] disables built-in tools in this lesson.

06

Claude response and usage

Claude returns model output and usage. This cloud boundary is separate from the browser-to-host connection.

07

Async SDK messages: assistant and result

for await...of consumes SDK messages. Assistant text and the final result are different message types.

08

Stream selected JSON events

The server forwards a small, explicit event projection as newline-delimited JSON. It does not stream raw runtime configuration.

09

Show answer, final status and evidence

The UI renders text safely and reports success only from a successful final SDK result.
