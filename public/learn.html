One SDK entry point

02

An async message iterator

query() returns an async iterator. for await...of receives messages as the SDK runtime works.

03

A prompt and explicit options

The prompt describes the task. The model and options define the small teaching experiment.

04

Assistant text versus final result

Read text content from assistant messages. Check result.subtype and is_error before reporting success.

05

A local runtime and cloud model

The Agent SDK starts its runtime on the host. Claude model inference happens through the configured API provider.

06

Configuration and observable evidence

Load .env on startup, keep the key server-side, and compare the status, turns and estimated cost with the event list.

What you will build

A TypeScript web app and a terminal command that share the same small agent function. You submit a text prompt, observe the SDK messages, and inspect the final outcome.
