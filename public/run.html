YOUR FIRST CLAUDE AGENT SDK APPLICATION

Configure and run the app.

Follow these steps from installation to your first observed SDK result.

Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Check the prerequisites

Use Node.js 24 or newer, npm, and an Anthropic API key with access to the model you select. On Windows, install Git for Windows if the SDK asks for Git Bash. The pinned SDK installs its Claude runtime through an optional platform package; keep optional dependencies enabled.

node --version
npm --version
02

Install and create your .env file

From the presentations directory, run the commands below. If you cloned this application from GitHub, start in the repository root and skip the first cd command. Preserve an existing .env rather than overwriting it.

cd .\agent-sdk\lesson-s01-query
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env

Enter your own key in .env. This is a safe template, not a real credential:

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3101

No Managed Agents agent ID or environment ID is required. Select a model available to your account. The SDK does not load .env itself; the npm scripts use Node’s --env-file-if-exists=.env startup option.

03

Windows: resolve Git Bash if needed

If the runtime cannot find Git Bash, add its actual executable path to .env. A common installation is:

CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

If the runtime binary is missing after installation, run npm ci without --omit=optional. No separate global Claude installation is normally needed for this pinned SDK on supported platforms.

04

Start the application

npm start

Keep the terminal running and open http://127.0.0.1:3101. Use the address printed by the server if you change PORT. Restart after editing .env. The server becoming ready does not perform a model call.

05

Run your first real query

  1. Open Application lab and confirm the server reports a configured key.
  2. Keep the default prompt or enter a short question.
  3. Press Run query() once.
  4. Read the initialized event, assistant text and final result.
  5. Confirm Success, one turn and an estimated cost. A final error outcome remains an error even if some text arrived.

Each click may incur API usage. This sample has no tool execution, no session resume and no transcript persistence. It permits one run at a time and aborts a run after 90 seconds or when its browser connection closes.

06

Run the same agent in the terminal

npm run agent -- "Explain an AI agent in one sentence."

# Check types and local message handling (no API call):
npm test

# Only after editing src/client.ts:
npm run build:client

The web and terminal versions both use src/agent.ts. npm start uses the prepared browser asset, so it does not rebuild the project each time.

Troubleshooting

SymptomWhat to check
Setup neededSave a real ANTHROPIC_API_KEY in .env and restart npm start.
Authentication or model errorCheck key validity, billing and access to CLAUDE_MODEL in your account.
Runtime or Git Bash not foundKeep optional npm dependencies enabled. Check the Windows path above.
Turn or budget limitUse a shorter text-only prompt. The final subtype explains the limit; it is not success.
Port in useIf this app is already running, open its printed URL. To restart after edits, press Ctrl+C in the original terminal first. For a different service, stop it or choose another PORT in .env.
Browser cannot connectThe local terminal must remain running. Use 127.0.0.1 and the configured port.
